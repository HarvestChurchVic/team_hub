# Harvest Team Hub (volunteer website)

Served at https://team.harvestchurch.org.au/ by GitHub Pages.

- `content.json` is updated automatically from the leaders' hub on claude.ai. Do not edit it by hand.
- `index.html` is the read-only hub app. It loads `content.json` on every visit.
- `404.html` is a copy of `index.html` so links like /switcher open that role.
